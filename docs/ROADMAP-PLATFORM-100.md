## ৪. দিন-ভিত্তিক কাজ

### ফেজ-১ (দিন ৭৫–৮৪): ইউজার-ফ্রেন্ডলি ভিত্তি — "প্রথম ৩ মিনিট"

| দিন | কাজ |
|---|---|
| **৭৫** | শেয়ার-সুইপ (পুরনো রোডম্যাপের শেষ আইটেম — ফেজ-৭ আনুষ্ঠানিক বন্ধ) |
| **৭৬** | প্রথম-রান কোচ-মার্ক v2: প্রথম বইয়ের যাত্রায় ৬-ধাপ হাইলাইট-ট্যুর + "স্যাম্পল বই খুলে দেখুন" এক-ক্লিক |
| **৭৭** | উইজার্ড-সরলীকরণ: ৩ প্রশ্ন (কী বানাবেন? কার জন্য? কোন মাপ?) → টেমপ্লেট অটো-পিক + লাইভ-প্রিভিউ |
| **৭৮** | এম্পটি-স্টেট সুইপ: প্রতিটা প্যানেল/তালিকায় বাংলা নির্দেশ + ১টা করে অ্যাকশন-বোতাম |
| **৭৯** | মানবী-এরর সুইপ: সব `alert/throw` → বাংলা টোস্ট + "সমাধান" বোতাম (নিয়ম: প্রতিটা এররে পরবর্তী পদক্ষেপ থাকবে) |
| **৮০** | Ctrl+K সার্চ-সর্বত্র: ফিচার + সেটিংস + টেমপ্লেট + প্রশ্ন-ব্যাংক + হেল্প — এক ইনপুটে |
| **৮১** | হোম-আপগ্রেড: সাম্প্রতিক-ডক থাম্বনেইল + "চালিয়ে যান" বড়-বোতাম + আটকে-পড়া-কাজের ইঙ্গিত |
| **৮২** | মোবাইল-রিডার মোড: ফোনে পড়া/শেয়ার/প্রশ্ন-ব্যাংক ব্রাউজ (সম্পাদনা নয় — সাবধানী বার্তাসহ) |
| **৮৩** | ইন-অ্যাপ হেল্প: প্রতিটা ডায়ালগে "?" বোতাম → বাংলা ব্যাখ্যা-প্যানেল (কেন এই ফিচার, কীভাবে কাজ করে) |
| **৮৪** | ফেজ-সুইপ + ফিডব্যাক-বাটন সব স্ক্রিনে (লোকাল জার্নাল + ঐচ্ছিক ক্লাউড) |

### ফেজ-২ (দিন ৮৫–৯৪): ত্রুটি-শিকার অভিযান-১ — "ভাঙবে কোথায়?"

| দিন | কাজ |

| **৮৮** | পুরনো-ডেটা আপগ্রেড-পথ: প্রতিটা ঐতিহাসিক স্কিমা-ভার্সনের মাইগ্রেশন-যাচাই + ব্যাকআপ-আগে-মাইগ্রেট |

| **৯২** | সহযোগিতা-এরর: পিয়ার-অফলাইন মাঝপথে, প্রেজেন্স-সার্ভার ডাউন, ধীর-নেট — সব ক্ষেত্রে সালাম-সেজদা ডিগ্রেডেশন |
| **৯৩** | মেমোরি/স্টোরেজ-কোটা: ব্রাউজার-কোটা শেষে মানবী প্রম্পট + নিরাপদ পরিষ্কার-টুল (পুরনো স্ন্যাপশট/কাস্ট) |

## ৫. তিন সুতোর বৈশিষ্ট্য-গ্যারান্টি (প্রতিটা নতুন ফিচারে বাধ্যতামূলক)

**ইউজার-ফ্রেন্ডলি গ্যারান্টি:**
- প্রতিটা নতুন ডায়ালগ/টুলে **"?" হেল্প** + এম্পটি-স্টেট + বাংলা লেবেল (ত্রিভাষা কী)
- প্রতিটা নতুন টুলে **বাংলা টিউটোরিয়াল-অনুচ্ছেদ** (হয় গাইডে, হয় ট্যুরে)
- প্রতিটা এরর-মেসেজে **সমাধান-প্রস্তাব** ("যা করবেন পরের লাইনে")
- ৪৪px টাচ-টার্গেট + কিবোর্ড-পৌঁছনীয়তা ডিফল্ট

**ত্রুটি-শিকার গ্যারান্টি:**
- প্রতি ফেজ-শেষে ত্রুটি-রেজিস্টার আপডেট (খুঁজে পাওয়া + ফিক্স দুটোই লেখা)
- কোনো সাইলেন্ট-ব্যর্থতা না: প্রতিটা ব্যর্থতায় ব্যবহারকারী জানবে + ডেটা বাঁচবে
- প্রতিটা ফিক্সের পুনঃপরীক্ষা পরের দিনেই (রিগ্রেশন-নজর)

**অ্যাডভান্সড গ্যারান্টি:**
- অ্যাডভান্সড টুল সবসময় **ঐচ্ছিক-প্রগতিশীল** — নতুন ব্যবহারকারী কখনো আটকাবে না
- local-first ভাঙে না: ক্লাউড/AI কিছুই বাধ্যতামূলক হবে না
