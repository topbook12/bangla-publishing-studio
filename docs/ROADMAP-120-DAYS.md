# রোডম্যাপ দিন ৬১–১২০ (Cycle-2) — বাংলা পাবলিশিং স্টুডিও

> দিন ১–৬০ (Phase-1→6) সম্পূর্ণ + Phase-1 গুণ-বেসলাইন (১১ অপরিহার্য) সম্পূর্ণ +
> Cycle-1 ফিডব্যাক-লুপ সম্পূর্ণ। এই ডক দিন ৬১–১২০-এর জীবন্ত পরিকল্পনা —
> প্রতি ফেজ-শেষে অ্যানালিটিক্স ও ইউজার-ফিডব্যাকে পুনঃঅগ্রাধিকার হবে।

## অবস্থা (দিন ৬১-এর শুরুতে)

| মেট্রিক (দিন-৬০ টার্গেট) | অবস্থা |
|---|---|
| প্রিন্ট-নির্ভুলতা ১০০% + PDF পথ | ✅ প্রিন্ট-পোর্টাল (Normal/Forma) + DOCX/EPUB/HTML/JSON |
| টেমপ্লেট লুপ-যাচাই ৫৫ DS + ৯ QP + কমিউনিটি প্যাক | ✅ ৫৫ DS (৪৬২০-বিল্ড সুইপ ০-ত্রুটি) + ৯ QP · ⏳ কমিউনিটি প্যাক → **দিন ৬১** |
| ক্লাউড-সিঙ্ক স্থিতিশীল + শেয়ার | ✅ শেয়ার-ভিউয়ার · ⏳ সিঙ্ক-স্থিতি (Turso ক্রেডেনশিয়াল ইউজার-সাইডে) |
| রাজস্ব Free/Pro + প্রথম পেমেন্ট | ✅ Free/Pro লাইভ · ⏳ প্রথম পেমেন্ট (গেটওয়ে ইউজার-সাইডে) |
| ফানেল কনভার্শন-টিউনড | ⏳ ফিডব্যাক-ইঞ্জিন লাইভ; ট্রাফিক আসার পর টিউনিং |
| E2E-কভারেজ Playwright সুইট | ✅ agent-browser গোল্ডেন-পাথ (হার্ড-রুল: টেস্ট-ফাইল কমিট নয়) |

| **৬৩** | প্রেজেন্স-অনলি সহযোগিতা (Yjs-ফলব্যাক): mini-service + কে-কী-লিখছে ব্যাজ |

| **৬৭** | QP মিক্স-জেনারেটর: ব্যাংক থেকে সেট-A/B অটো-মিক্স + উত্তরপত্র |
| **৬৮** | বই-টেমপ্লেট প্যাক: গল্প/উপন্যাস/কবিতা/প্রবন্ধ চ্যাপ্টার-স্টাইল সেট |
| **৬৯** | মাদ্রাসা/সংস্কৃত/হিন্দি টাইপোগ্রাফি প্যাক (ফন্ট-জোড় + সংখ্যা-প্রথা) |
| **৭০** | ফেজ-৭ সুইপ + প্যাক-ইকোসিস্টেম ডক (বাংলা টিউটোরিয়াল) |
| **৭১–৭৫** | সহযোগিতা-হার্ডেনিং: সংঘর্ষ-নিরাপদ মার্জ, প্রেজেন্স-কার্সর, শেয়ার-সুইপ |
