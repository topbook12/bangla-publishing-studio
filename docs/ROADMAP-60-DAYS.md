# ৬০ দিনের বিজনেস রোডম্যাপ — Bangla Publishing Studio

> **লক্ষ্য:** শক্তিশালী টুল থেকে **পূর্ণাঙ্গ বিজনেস প্ল্যাটফর্ম** — ৬০ দিনে, প্রতিদিন কার্যকর উন্নয়ন, কোনো গ্যাপ নেই।
> **পদ্ধতি:** প্রতিদিন = গভীর বিশ্লেষণ → বাস্তবায়ন → ব্রাউজার-যাচাই (E2E) → commit + push → worklog।
> **ভিত্তি:** গভীর কোড-অডিট (৩টি স্বতন্ত্র অডিট: আর্কিটেকচার ~৫৯ক লাইন, margin/page-fidelity ডাটাফ্লো, UX/প্রোডাক্ট-গুণ)।

### যা নেই (বিজনেস-গ্যাপ — রোডম্যাপের মূল টার্গেট)
1. **PDF এক্সপোর্ট নেই** — প্রেস-রেডি ফরমা থাকাও সত্ত্বেও সরাসরি PDF পথ নেই
2. **অ্যাকাউন্ট/ক্লাউড নেই** — ডেটা ডিভাইসে-আটকে (churn/ব্যাকআপ ঝুঁকি); Prisma অব্যবহৃত
3. **মনিটাইজেশন শূন্য** — কোনো প্ল্যান/পেমেন্ট/কোটা নেই (PPill `pro` টোন ও AI রেট-গার্ড প্রস্তুত অ্যাঙ্কর)
4. **ল্যান্ডিং/মার্কেটিং পেজ নেই** — ভিজিটর কনভার্ট হয় না; অ্যানালিটিক্স শূন্য (ফানেল অদৃশ্য)
5. **fidelity drift** — স্ক্রিন/প্রিন্ট/এক্সপোর্টে সূক্ষ্ম মার্জিন-অসঙ্গতি (দিন ১-এ মূল উৎস ধ্বংস)
6. **Legal কাগজ শুধু QP-তে**, QP-র কাগজ-মাপ সন্নিবেশে উপেক্ষিত, বুক-ব্লুপ্রিন্টে মার্জিন অসেট নয়
7. **অনবোর্ডিং ট্যুর/টেস্ট-কভারেজ নেই**, কয়েকটি ১০০০+ লাইনের দৈত্য-ফাইল

## ৯. প্রতিদিনের অপরিবর্তনীয় কর্মপদ্ধতি (No-Gap Protocol)

1. **গভীর বিশ্লেষণ** — সেদিনের টার্গেটের কোড/ডাটাফ্লো আগে পড়া; মূল-কারণ খোঁজা, লক্ষণ নয়
2. **বাস্তবায়ন** — ছোট, নিরাপদ, ধাপে-ধাপে; হার্ড-রুল অক্ষুণ্ণ (প্রতি-পাতা আইসোলেশন, local-first, ত্রিভাষা)
3. **যাচাই** — `tsc` + `lint` + **agent-browser E2E** (প্রতিটি পরিবর্তন ব্রাউজারে হাতে-ঘোরানো, মাল্টি-রাউন্ড)
4. **সংরক্ষণ** — commit + push origin/main (প্রতিদিনের কাজ কখনো জমতে দেব না)
5. **রেকর্ড** — worklog.md-তে Task ID/Work Log/Stage Summary
6. **রিপোর্ট** — ব্যবহারকারীকে বাংলায় সংক্ষিপ্ত ফলাফল + আগামীকালের প্ল্যান

### অপরিবর্তনীয় হার্ড-রুল (প্রতিদিন প্রযোজ্য)
- **প্রতি-পাতা সম্পাদনা-আইসোলেশন** — এক পাতার বদল অন্য পাতায় ছড়াবে না
- **local-first** — ক্লাউড চলে গেলেও সম্পাদনা অব্যাহত থাকবে
- **ত্রিভাষা সম্পূর্ণতা** — নতুন প্রতিটি স্ট্রিং bn/hi/en
- **সবুজ ব্র্যান্ড সামঞ্জস্য** — নতুন UI-ও Grand Ink টোকেন ব্যবহার করবে
- **কোনো টেস্ট-ফাইল কমিট নয়** — যাচাই ব্রাউজারে/ইনলাইনে
