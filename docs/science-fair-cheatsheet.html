১ · শুরুর গল্প — "করিম সাহেবের প্রশ্নপত্র" (৪০ সেকেন্ড)

শিক্ষক করিম সাহেব Word-এ প্রশ্নপত্র বানালেন → যুক্তাক্ষর ভাঙা, প্রশ্ন কাগজের ভাঁজে কাটা পড়া, ২০০ কপি নষ্ট। বই ছাপাতে গেলে কারিগর বললেন "ফরমা" আনেন — ফরমা বানানোর সফটওয়্যার (InDesign) = ৩ মাসের বেতন + মাস দেড়েক শেখা + পুরোটা ইংরেজি। তখনই প্রশ্ন: বাংলা বই ছাপার এত কষ্ট কেন? তাই — Bangla Publishing Studio: ব্রাউজারে খোলে, ইন্টারনেট ছাড়া চলে, ছাপার সব নিয়ম নিজে থেকেই মানে।

প্রকাশক — ফরমা + দামি ইংরেজি সফটওয়্যার
সমাধান — ব্রাউজারে পুরো স্টুডিও, সার্ভার ছাড়া
ফিচার — ৫৫ টেমপ্লেট, আসল পাতা, ফরমা, প্রশ্ন-ব্যাংক
অফলাইন ফাঁদ — WiFi বন্ধ → সব চলে
বাস্তবতা — প্রিন্ট-রেডি PDF + DOCX এক্সপোর্ট

৩ · লাইভ ডেমো রুট (ধাপ = অ্যাকশন + এক বাক্য)

#অ্যাকশনবলার বাক্য
১হোম → টেমপ্লেট স্টুডিও → ৫৫ টেমপ্লেট → বই তৈরি"উপন্যাস, প্রশ্নপত্র, থিসিস — রেডিমেড; কমিউনিটি প্যাকও ইমপোর্ট হয়।"
২⭐ বাংলা টাইপ → পাতা ভরে অটো পরের পাতায়"Word এক লম্বা স্ক্রল; এখানে স্ক্রিনে যা, কাগজে তা-ই।"
৩A4 → Demy Octavo মাপ-বদল"ছাপাখানার আসল কাগজের নাম জানে।"
৪৯ ফন্ট + বাংলা পৃষ্ঠা-সংখ্যা ১২৩ + যুক্তবর্ণ প্যালেট"মাদ্রাসা/সংস্কৃত/হিন্দি টাইপোগ্রাফি প্যাক আছে।"
৫Ctrl+K কমান্ড প্যালেট"সব ফিচার এক জায়গা থেকে।"
৬⭐ প্রশ্ন-ব্যাংক (ট্যাগ/শ্রেণি/জটিলতা) → Set-A/B + উত্তরপত্র"শিক্ষকের ভান্ডার থেকে এক ক্লিকে দুই সেট — কপি কমবে, ঘুম ফেরবে।"
৭⭐ Ctrl+K → "ইতিহাস" → তুলনা → শব্দ-লেভেল ডিফ + পাতা-রোলব্যাক"কে কী বদলেছে রঙিন দেখায়; এক পাতাও ফেরত আনা যায়।"
৮২য় উইন্ডো → রিমোট কার্সর + মার্জিন কমেন্ট"সম্পাদক-লেখক একসাথে; মার্জ সংঘর্ষ-নিরাপদ।"
৯⭐⭐ WiFi বন্ধ → টাইপ + সেভ চলতেই থাকে"ডেটা আপনার কম্পিউটারেই — কোথাও আপলোড হয় না।"
১০Ctrl+P প্রিভিউ + DOCX/JSON এক্সপোর্ট (ছাপা পাতা দেখাও)"ছাপাখানা যা চায়, তাই বেরোয়।"
১১ফরমা ভিউ — এক কাগজে ৪ পাতা"গল্পের সেই 'ফরমা' — এখন এক ক্লিক।"
ওয়াও-১: পাতার অটো-ফ্লো — Word-এ এটা নেই
ওয়াও-২: এক ক্লিকে Set-A/B + উত্তরপত্র
ওয়াও-৩: WiFi বন্ধ করার সাহস — কিচ্ছু থামে না
পাকা-মন্ত্র: "আসল কাগজের পাতা + ছাপাখানার ফরমা + অফলাইন চলা + পুরোপুরি বাংলা — এই চার একসাথে ফ্রিতে আগে কোথাও ছিল না।" — যেকোনো তর্কে এই ত্রয়ী ফেরত আনো।

প্রশ্ন-উত্তর চিটশিট

জুরির আগ্রাসনের জায়গা = তোমার গর্বের জায়গা
প্রযুক্তি
কী দিয়ে বানানো?
Next.js + React + TypeScript (জনপ্রিয়তম ওয়েব প্রযুক্তি); এডিটর TipTap/ProseMirror (Google Docs ঘরানার ওপেন-সোর্স ইঞ্জিন); ডেটা IndexedDB।
ডেটা কোথায় থাকে?
ব্রাউজারের ভিতরের ডেটাবেসে — প্রতি টাইপে অটোসেভ; JSON ব্যাকআপও ডাউনলোড করা যায়। কোথাও আপলোড না — এটা বৈশিষ্ট্য, বাগ না।
AI ব্যবহার করেছ?
কোডিং-সহায়ক হিসেবে হ্যাঁ; ডিজাইন-সিদ্ধান্ত, ফিচার, পরীক্ষা আমার। অ্যাপের ভিতরে কোনো AI লাগে না — সব লোকাল।
একা বানিয়েছ?
ডিজাইন-সিদ্ধান্ত আর ফিচার সব আমার; AI দ্রুত কোডে সাহায্য করেছে — পেশাদার প্রকৌশলীরাও আজ এভাবেই কাজ করেন।
ওপেন সোর্স? দাম?
হ্যাঁ, GitHub-এ পাবলিক; কোর ফ্রি। Pro স্তর আছে — প্রজেক্ট সাসটেইন করার পরিকল্পনা।
তুলনা
Word/Google Docs থেকে পার্থক্য?
Word জানে না "কাগজ" — এক লম্বা স্ক্রল; এখানে আসল পাতা, গাটার, ফরমা, বাংলা সংখ্যা। Docs ইন্টারনেট ছাড়া পুরো চলে না ও ডেটা কোম্পানির সার্ভারে।
InDesign থাকলে কেন এটা?
ইনডিজাইন দামি + ইনস্টল + প্রশিক্ষণ + ইংরেজি। আমারটা ফ্রি, ব্রাউজারে, বাংলা-প্রথম, অফলাইন-ফার্স্ট — করিম সাহেবের জন্য।
সবচেয়ে কঠিন সমস্যা?
সত্যিকারের পেজিনেশন (লেখা পাতার সীমায় ফ্লো), বাংলা যুক্তাক্ষর, আর ফরমার অঙ্ক — কোন পাতা উল্টো বসবে।
ব্যবহার ও সমাজ
কারা ব্যবহার করবে?
শিক্ষক-কোচিং (প্রশ্ন-ব্যাংক, Set-A/B), লেখক, মাদ্রাসা-সংস্কৃত শিক্ষা, ছোট প্রকাশনী — যারা DTP কারিগর ভাড়া করতে পারে না।
সমাজের লাভ?
ফরমা = এক কাগজে চার পাতা = কাগজ/খরচ অর্ধেক; শিক্ষকের সময় বাঁচে; গ্রামের লেখক নিজের বই নিজে বানায় — প্রকাশনা গণতায়িত হয়।
নিরাপত্তা ও সহযোগিতা
লেখা হারাবে না?
প্রতি টাইপে অটোসেভ + ৫ মিনিটে অটো-স্ন্যাপশট + ভার্সন-ইতিহাসে রোলব্যাক (পুরো বই বা একটা পাতা) + JSON ব্যাকআপ।
অন্য কেউ পড়বে?
না — কিছুই আপলোড হয় না, local-first। গোপনীয়তা ডিজাইনের অংশ।
দুইজন একসাথে?
হ্যাঁ — রিমোট কার্সর, "কে লিখছে" ব্যাজ, মার্জিন কমেন্ট + @উল্লেখ, ক্লাউড-পুলে ৩-ওয়ে কনফ্লিক্ট-সেফ মার্জ।
জুরি-বাড়তি
বড় ইনোভেশন কোনটা?
"শূন্য-কনফিগ প্রকাশনা" — ইনস্টল/অ্যাকাউন্ট/ইন্টারনেট ছাড়াই ছাপার-মাপের বই; প্রথমবার খুলেই শিক্ষক কাজ শেষ।
করা হয়নি কিছু?
স্বীকার করি: রক্ত-মার্জিন/ক্রপ-মার্ক চেক, ওয়ান-ক্লিক সার্ভারলেস PDF, মেরুদণ্ড-ক্যালকুলেটরসহ কভার-ডিজাইনার — সব ১২০-দিনের রোডম্যাপে আছে (দুর্বলতা না, পরিকল্পনার প্রমাণ)।
কাজ করে কী করে জানবেন?
প্রতিটা ফিচার ব্রাউজারে শেষ-থেকে-শেষ পরীক্ষা করি; লিন্টার + টাইপ-চেকার প্রতি পরিবর্তনে চলে।
এটা Word-এর কপি?
Word লেখার টুল, আমারটা ছাপার টুল — Word যে ফাঁক ভরাট করে না (কাগজ/ফরমা), সেটাই আমি ভরাট করেছি।
প্রিয় ফিচার?
অফলাইন ফাঁদ — WiFi বন্ধ করার সাহস যে টুলে আছে, সেটাই সবার কাছে পৌঁছাবে।

প্রতিরক্ষার ৩ মন্ত্র

  1. না জানলে: "দারুণ প্রশ্ন — রোডম্যাপে আছে, আপনার পরামর্শ নিচ্ছি।"
  2. তর্কে: ত্রয়ী ফেরত — অফলাইন + বাংলা + ফরমা, ফ্রিতে।
  3. মেশিন আচরণ করলে: "এটাই লাইভ-ডেমোর মজা!" → স্যাম্পল/স্ক্রিন-কাস্ট।

৩০-সেকেন্ড পিচ (ভিড়ের জন্য)

"বাংলা বই ছাপাতে Word ঝামেলা দেয়, ছাপাখানার সফটওয়্যার দামি। আমি বানিয়েছি ব্রাউজারে চলা ফ্রি স্টুডিও — আসল কাগজের পাতা, ফরমা, Set-A/B মিক্স, WiFi বন্ধেও চলে। ডেটা নিজের কম্পিউটারে, ওপেন সোর্স।"

মেলার আগের রাতের চেকলিস্ট

  • git clone github.com/topbook12/bangla-publishing-studio
  • bun install → bun run dev → localhost:3000
  • ব্রাউজারে PWA ইনস্টল করে রাখো
  • ৩–৪ পাতার স্যাম্পল বই বানিয়ে সেভ
  • প্রশ্ন-ব্যাংকে ৮–১০ প্রশ্ন (ট্যাগ/শ্রেণি/জটিলতা)
  • WiFi বন্ধ করে পুরো ডেমো প্র্যাকটিস
  • ফোনে ৯০-সেকেন্ড স্ক্রিন-কাস্ট (ফলব্যাক)
  • ছাপা ১ পাতা A4 স্যাম্পল (ছাপা-প্রমাণ)
  • চার্জার + মাউস + ল্যাপটপ স্ট্যান্ড
  • এই চিটশিট ২ কপি প্রিন্ট
  • ঐচ্ছিক: cd mini-services/presence-service && bun run dev (রিমোট-কার্সর ডেমো)
  • শেষ বাক্য মুখস্থ: "প্রযুক্তি যখন মায়ের ভাষায় কথা বলে, তখন রাত জাগা করিম সাহেবরা ঘুমাতে পারেন।"
